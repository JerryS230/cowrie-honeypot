# cowrie-honeypot
A comprehensive Cowrie SSH honeypot deployment with analysis tools, logging, and security monitoring

The goal of this project is for me to create something that is cost-effective for the average student to make while being a legitimate project where you can speak to VPS hardening, honeypot deception tooling, log pipelines, and dashboarding, all of which map directly onto SOC analyst / cloud security / detection engineering roles.
